Database evidence and interpretation

The full verification checks the visible heap aggregate against stored roots. It does not validate every internal node or prove exact table equality. XOR aggregates are not membership proofs.

Snapshots briefly hold a SHARE lock on the inspected heap. Reads can wait for writers; timeouts are reported. Writes commit first, then the UI reads a fresh snapshot. An external writer can change that later snapshot.

Tree browsing supports current format 10 / route 4 / row hash 1. Per-node row lookup uses native single-key routing only when the key descriptor matches that helper. Other indexes retain the real tree and full-table row view.
