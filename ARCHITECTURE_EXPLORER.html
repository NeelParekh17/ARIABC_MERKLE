Which code path each published result exercised

The same binaries run in very different shapes. Single-node runs bypass Raft and Kafka entirely. Each row lists the exact flags the harness passes.

These results predate the det safety fixes in c165637f. On the benchmark workloads the new paths never fire (dt_opf = 0, dt_rel_read_tags = 0), and the TPC-C v2 A/B stays within ±1 %. The 4-node cluster has not yet been rerun on the new build.
