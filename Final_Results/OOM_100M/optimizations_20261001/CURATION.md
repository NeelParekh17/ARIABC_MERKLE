# Archive policy (2026-10-01)

Every file in the five measured run directories and the WAL dry-run directory
was copied without exclusions. Controller shell scripts, logs, status files and
fillfactor preparation output were also copied. `archive_mapping.json` maps
source runs to published runs. Fillfactor-100 controls duplicate WAL-off evidence;
they are the same observations, not additional trials. Original mode names,
absolute paths, campaign hashes and raw summaries remain unchanged.

`ARCHIVE_SHA256SUMS` checks every copied raw/provenance file from this directory.
`provenance/scripts/` contains current publication-time source snapshots; campaign
`source_sha256` identifies the controller code at execution and executable
SHA256s in setup/result identify the actual remote binaries. A current source
snapshot alone does not establish which source built that binary.

`provenance/report_H.md` and `provenance/overhead_analysis/` preserve the separate
overhead analysis. Its supplied plain-SQL probe percentages are qualified as
reported probe evidence, not instrumentation from these two campaigns.

Derived summary/comparison CSVs, tables and figures are regenerated by
`scripts/distributed/oom_opt/plot_opt.py`. Only their artifact path labels change;
raw evidence is never rewritten. No SSH, build, database, test or benchmark was
run while publishing these artifacts.
